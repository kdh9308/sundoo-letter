# 선두교회 신혼부부회 ｜ 스승의 주일 편지 사이트

## 🟢 사용법 — 더블클릭 한 번이면 끝

**`편지 사이트 열기.bat`** 파일을 더블클릭하세요.

- PowerShell 창이 하나 뜨고
- 자동으로 브라우저에 `http://localhost:8000/` 가 열리며
- 사이트가 바로 표시됩니다.

> 처음 실행할 때 Windows 보안창이 뜨면 "추가 정보 → 실행" 을 누르거나, `편지 사이트 열기.bat` 파일에 우클릭 → 속성 → 하단 "차단 해제" 체크 후 적용 해주세요.

### 종료 방법
검은 PowerShell 창을 닫으면 서버도 함께 종료됩니다.

---

## 폴더 구성

```
sundoo-letter/
├── 편지 사이트 열기.bat   ← ⭐ 이걸 더블클릭
├── server.ps1             ← 로컬 웹서버 (PowerShell)
├── index.html             ← 메인 페이지
├── style.css              ← 스타일 (벚꽃 핑크 테마)
├── script.js              ← 인터랙션 로직
├── video/
│   └── letter.mp4         ← 신혼부부회 영상 (이미 들어있음)
└── README.md
```

## 동작 흐름

1. 벚꽃 흩날리는 핑크빛 하늘 + 선두교회 일러스트 + 종이비행기
2. 화면 한 번 탭 → 비행기가 곡선 자취 그리며 날아오름
3. 편지가 손글씨 폰트로 펼쳐짐 (인사말 / 본문 / 서명)
4. 영상 편지가 자동 재생 (소리 포함)
5. 영상 종료 후 "처음부터 다시 보기" 버튼

## 편지 글귀 수정

`index.html` 에서 아래 부분을 원하시는 내용으로 바꿀 수 있어요:

```html
<h2 class="letter-greeting">사랑하는 목사님께</h2>
<p class="letter-body">
  늘 따뜻한 말씀과 사랑으로<br />
  저희 신혼부부들의 가정을 돌보아주시는<br />
  목사님께 깊은 감사를 드립니다.
</p>
```

수정 후 저장하고 브라우저에서 새로고침(F5)만 하면 바로 반영됩니다.

## 폰트
Google Fonts (Nanum Myeongjo, Nanum Pen Script, Gaegu, Noto Sans KR) 를 인터넷에서 받아옵니다. 인터넷 연결이 안 되면 시스템 기본 폰트로 표시돼요.

## 자주 묻는 것

**Q. 영상 자동재생이 안 돼요**
→ 처음 한 번 화면을 탭(클릭)해야 합니다. 비행기 위 또는 화면 아무 곳이나요. 이게 모바일 브라우저의 보안 정책상 우회 불가능합니다.

**Q. 포트 8000이 이미 쓰이고 있다고 나와요**
→ `server.ps1` 안의 `$ports = @(8000, 8080, 5500, 3000, 9000)` 에서 자동으로 다음 후보를 시도합니다. 다섯 개가 다 막혀 있는 경우는 거의 없어요.

**Q. 다른 컴퓨터에서도 보고 싶어요**
→ 폴더 자체(`sundoo-letter`)를 그대로 USB로 옮기거나 압축해서 보내고, 받은 쪽에서 똑같이 `편지 사이트 열기.bat` 더블클릭하면 됩니다.
